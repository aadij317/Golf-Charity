# Golf Charity frontend redesign

The frontend has been updated to the approved light Golf Charity visual direction:
- cream/white surfaces with deep fairway-green accents
- Fraunces display typography with clean Inter UI typography
- rounded SaaS cards, soft borders and restrained shadows
- photography-led landing page and charity cards
- redesigned landing page, sign-in, account creation, charity directory and draw results
- shared UI token update so dashboard, subscription and admin screens inherit the same light design language
- redesigned admin navigation, page headers, search input, stat cards and report chart colors

Backend routes, Supabase access, authentication flow, server actions and database queries were intentionally preserved.
